# Tasks from the original club app

Kabine started as the app of one handball club, which is still developed on its own. New features and bug fixes made there are listed here so they can be brought into Kabine. Whoever works on Kabine takes an open entry, ports it the Kabine way (English source, Lingui, club profile instead of club data, modules, tests) and moves it to "Done" with the Kabine commit.

Entries describe the change, not the club: no names, domains or data of the club.

Format per entry: date, title, what changed and why, where in the code (file and function names are the same in both code bases unless noted), and anything that needs adapting for Kabine.

## Open

- **2026-10-26 Children in the app: limits per age class, plus a coach override per team (Kabine).** What players of a youth age class may do themselves becomes a ceiling with three levels; each level can only restrict further: (1) age class, set by admins: own account yes/no, respond themselves, chat none/read/write, answer help requests; (2) team, set by coaches, only in Kabine (not built in the club app): may restrict further than the age class, e.g. chat off for children so that only parents are in; (3) parents' permissions per child, within (1) and (2). Without an own account: no player invitation link for that team (older links stop working), no personal link for a child who only plays in such teams (admins excepted), parents respond and are in the chat, chat push and badge skip the child. A child who has an account through another team sees that team's events but cannot respond or chat there. Adult classes and groups are never limited. Club app: migration `0025_child_access.sql` adds `age_classes.child_account`, `child_respond`, `child_chat` ('none'|'read'|'write'), `child_help` (defaults: everything allowed; the club restricted F and E youth); `worker/domain/child-limits.ts` (`LIMITED_TEAMS_SQL`, `toLimits`, `childAccountAllowed`, `CHILD_CHAT_OFF_SQL`), `Actor.teamLimits` and `childLimitAllows` in `worker/auth/actor.ts` used by `mayActFor`/`requireActFor` (responses, help requests), `chatAccess` in `worker/routes/chat.ts`, `chatPushRecipients` in `worker/chat/room.ts`, `worker/domain/badge.ts`, invites in `worker/routes/teams.ts` and `worker/routes/join.ts`, personal links in `worker/routes/persons.ts`, age class routes keep the values when an older client omits them (`writeAgeClasses`), the new season copies them. App: four columns in the age class editor, notice on the invitations tab and the child page of parents, deadline hint only when the child can decline. Tests: `test/child-access.test.ts`, e2e "Kinder in der App". Kabine: use the same column names, defaults per age class in the sport profile (`shared/sports.ts`), a new timestamped migration with an upgrade test, a nullable team-level override (e.g. `teams.child_limits` JSON) with a coach UI in the team settings, Lingui texts; once ported, regenerate the club app's `test/kabine-schema.json` so its export carries the columns.

- **2026-10-26 Groups can include parents.** A group (chat and special events only) used to have no parents. A youth group with children (e.g. goalkeeper training across teams) showed its events only to children with their own access. Now groups have the "Include parents" switch like teams (admins, default off). With it on, linked parents see the group's special events for their children, respond for them and are in the group chat; children with their own access then follow their parents' permissions, as in teams. No parent invitation links for groups: parents are linked through the child's team. Server: `PATCH /teams/:id` no longer rejects `parentsEnabled` for groups (`worker/routes/teams.ts`); visibility, chat access and chat push already follow `teams.parents_enabled`. App: switch in the group settings (`src/pages/group.tsx`), group explainer texts no longer say "no parents". Test in `test/groups.test.ts`. Kabine: texts through Lingui, decision entry replacing "groups have no parents".

## Done

- **2026-10-20 Only admins change their own name.** Ported as a fixed rule, not a club setting (the maintainer's decision: names are identity in a small, invitation-only club app with many children). Profile hint, coaches rename parents of their teams. Kabine: `4671b55`.
- **2026-10-20 Player invitation link while signed in: no name choice, only "Straight to the app".** Server refuses with 409 `signed_in` (options, e-mail code, verify, late code redemption); invalid links show signed-in people the box. Kabine: `f7031db`.
- **2026-10-20 Cancelled events read "Not taking place" and are struck through in the detail view.** Wording in app, push, calendar feed and conflict messages; struck-through hero. Kabine: `a70a3f2`.
- **2026-10-19 Invitation links are for setup only; "Straight to the app" when opened again.** Share texts and join page say the link is needed once; signed-in parents (and players) who open it again get "Straight to the app". Kabine: `f710472`.
- **2026-10-19 Record attendance after an event: present, excused, unexcused.** Coaches record per participant after the start, the response decides without an entry; coaches until the end of the following day, admins the whole season. Migration `202610192200_core_attendance-marks.sql` copies the unexcused marks; `unexcused_absences` is dropped in a later release. Kabine: `4c44e6f`.
- **2026-10-19 Coaches, group leads and organizers can say "I'm not there".** Leaders (coaches, group leads, team staff, creator and organisers of a special event) mark themselves absent with an optional note; other leaders get a push, the team only on request and without the note. New migration `202610192140_core_leader-absences.sql`. Kabine: `7435ac2`.
- **2026-10-19 Parent invitation: own name, not the child's.** Bold hint under the first name, warning with a confirm button when the first name is a child's of the team, passkey and e-mail code wait until confirmed. Kabine: `c8a56cd`.
- **2026-10-19 Picking players from other teams: filter by team, core squad marked, correct source teams in the hints.** Shared candidate list with team filter chips and a core squad badge in the three pickers; hints name lower-ranked teams of the same age class and the next younger youth team. Kabine: `8c96fdb`.
- **2026-10-18 Holiday plans in the timeline.** Notes "Autumn holidays, 26 Oct to 30 Oct: no training for wD" in the event overview. Kabine: `b3b1eb2`.
- **2026-10-18 Optional joint training.** Per team and training mandatory or optional, players accept by hand. Kabine: `ccc0934`, `13d83be`.
