# __VENDOR__

Spielpläne von __VENDOR__ (https://www.__DOMAIN__). Die [englische Fassung](README.md) enthält auch die technischen Einzelheiten.

- **Zugriff:** welche Schnittstelle, und warum sie verwendet werden darf (offizielle API, öffentlicher Export, Erlaubnis des Verbands). Die Nutzungsbedingungen verlinken.
- **Abgerufen von:** dem Server oder dem Gerät des Trainers, und warum; wie oft (docs/dev/connectors.md, Fair use).
- **Daten:** Spiele, Hallen, Ergebnisse. Keine personenbezogenen Daten.

## Link der Mannschaft

Wo ein Trainer den Link der Mannschaft bei __VENDOR__ findet, wie er aussieht (ein Muster mit erfundenen Nummern, jede Form, die `parseLink` erkennt) und dass er unter *Mannschaft → Einstellungen → Spielplan* eingefügt wird. Die App verlinkt diesen Abschnitt.
